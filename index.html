PEARL ABYSS · 만나모

동물타고 슝!

어떤 공모전인가?

「만들어봐, 나만의 모험!」, 줄여서 만나모는 펄어비스가 게임 인재 발굴과 제작 문화 활성화를 위해 개최한 공모전입니다. 3~6명이 팀을 이루어 검은사막 모바일 IP를 활용한 새로운 모바일 게임이나 콘텐츠를 기획하고, 기획서와 발표로 아이디어를 평가받습니다.

주최
펄어비스
참가 방식
3~6인 팀
공모 주제
검은사막 모바일 IP
심사
기획서 · PT

내가 한 활동

팀으로 캐주얼 러닝 액션 게임 「동물타고 슝!」을 기획했습니다. 게임의 콘셉트와 플레이 흐름, 성장 구조, 스테이지와 전이 동물을 상세 기획서로 정리해 장려상을 받았습니다.

기획한 게임

흑정령이 여러 동물로 전이하며 추격을 피해 검은 돌로 돌아가는 게임입니다. 동물별 능력, 타이밍 판정, 탑뷰와 사이드뷰를 오가는 시점 전환을 핵심 시스템으로 설계했습니다.

NEXON · NYPC 2026

Master Track

어떤 대회인가?

NYPC(Nexon Youth Programming Challenge)는 넥슨이 운영하는 프로그래밍 대회이며, Master Track은 대학생 대상 팀 부문입니다. 1~4명이 게임 규칙을 분석하고 전략과 AI 코드를 개발해 다른 팀의 코드와 자동 대전합니다.

Qualification Round의 「NEXT NATION」에서 승리 전략과 AI 코드를 만들고, 판단 근거를 정리한 리플레이 보고서를 제출했습니다.

PROJECT 01 · DESKTOP MUSIC TOOL

MidiPro

어떤 프로젝트인가?

MIDI 작곡과 편집, 가상악기, 믹싱과 기타 연주 보조 기능을 하나의 프로그램에서 사용할 수 있도록 만든 데스크톱 음악 작업 도구입니다.

PROJECT 04 · GAME UI AUTHORING TOOL

GameUI Studio

게임뿐 아니라 앱과 웹의 페이지·위젯 구조까지 시각적으로 편집하고, 버튼 동작과 화면 이동을 즉시 확인할 수 있도록 만든 데스크톱 UI 제작 도구입니다.

직접 구현한 기능

페이지·프레임·텍스트·이미지·버튼 편집, 계층 구조 재배치, 속성 인스펙터, 실행 프리뷰와 프로젝트 저장을 구현했습니다. 최신 버전에서는 Game·App·Web 유형별 템플릿과 캔버스 크기를 선택하는 3단계 프로젝트 생성 흐름도 추가했습니다.
