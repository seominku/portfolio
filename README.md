# 발표용 포트폴리오 프로토타입

구민서의 대회 참가와 프로젝트 5개를 소개하는 밝은 테마의 단일 페이지 웹사이트입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치나 빌드가 필요하지 않습니다.

발표 중에는 다음 키를 사용할 수 있습니다.

- `↓`, `Space`, `PageDown`: 다음 화면
- `↑`, `PageUp`: 이전 화면
- `Home`: 첫 화면
- `End`: 마지막 화면

## 파일

- `index.html`: 발표 내용과 화면 구조
- `styles.css`: 밝은 테마, 반응형 레이아웃, 프로젝트 시각화
- `script.js`: 방향키 이동, 진행률, 등장 애니메이션

대회 연도, 참가 작품명, 개인 역할, 사진과 영상은 자료가 준비되면 각 섹션에 추가할 수 있습니다.
